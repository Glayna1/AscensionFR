AUCUNE ÉCRITURE

Ce que cette page fait

  1. Lit la sourceFichier, chemin JSON et empreinte GitHub exacte.
  2. Compare les versionsAvant/après, ajout, modification ou suppression, mot par mot.
  3. Identifie l’auteurCompte GitHub ou identité enregistrée dans le commit.
  4. Affiche les votesRéactions et revues GitHub, avec les comptes publics concernés.
  5. Ne modifie rienAucun formulaire d’édition, aucune proposition, aucun vote depuis le site.

Aucun compte interne, aucune base privée, aucun jeton GitHub embarqué et aucun suivi publicitaire.
