AUCUNE BOÎTE NOIRE

Ce qui est public

  1. La sourceFichier, chemin JSON et empreinte GitHub exacte.
  2. La comparaisonAjout, modification ou suppression, mot par mot et caractère par caractère.
  3. La personneCompte GitHub de l’auteur de la proposition.
  4. Les votesRéactions +1 et −1, avec la liste publique des comptes.
  5. La décisionIssue, discussion, pull request et commit restent consultables.

Ce site n’utilise ni compte interne, ni base privée, ni suivi publicitaire.
